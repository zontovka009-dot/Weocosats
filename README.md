# Wathis

Первый визуальный прототип Telegram Mini App для совместного просмотра.

## Запуск
```bash
cd frontend
npm install
npm run dev
```

Сейчас интерфейс работает на mock-данных. Следующий этап: FastAPI, PostgreSQL, WebSocket, Telegram auth, приглашения, друзья, VK/Drive adapters и настоящий player.
