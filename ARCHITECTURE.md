# Wathis architecture

Frontend is deliberately component-oriented in the first prototype: real DOM/CSS controls instead of screenshot-like images. The mascot is a temporary CSS placeholder and can be replaced by the final Vachis asset later.

Backend is a minimal FastAPI/WebSocket skeleton. Next stage adds aiogram, PostgreSQL, Redis, Telegram auth, rooms, invitations, friends, saved sessions and provider adapters for VK/Google Drive.
